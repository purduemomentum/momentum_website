# Momentum at Purdue

Website for [Momentum at Purdue](https://www.purduemomentum.org), a student organization at Purdue University.

This project is a local copy of the public site at [purduemomentum/momentum_website](https://github.com/purduemomentum/momentum_website).

## Run locally

```bash
npm install
npm run dev
```

Then open [http://127.0.0.1:43123](http://127.0.0.1:43123).

## What’s in the repo

- `index.html` — full site (home, about, teams, projects, apply)
- `styles.css` — visual system matched to the momentum wordmark (black, white, pink / yellow / cyan)
- `logo.png` — official wordmark
- `404.html` — GitHub Pages fallback
- `headshots/` and `founders_headshots_website/` — team photos
- `project_images/` — project and track artwork
- `CNAME` — production domain (`www.purduemomentum.org`)
